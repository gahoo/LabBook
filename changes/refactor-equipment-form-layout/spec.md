# 重构仪器编辑表单开放时间与规则布局 (Refactor Equipment Form Layout)

## 背景 (Background)
在管理后台编辑仪器的侧边抽屉（宽度约 500px~600px）中，原有“开放时间设置”将大量输入项与开关混在单一的灰色大容器中，缺乏清晰的视觉边界。为了在视觉上按业务逻辑清晰区分不同区域，需将其结构化为各自独立的卡片包裹。

## 目标 (Goals)
1. **视觉分块清晰**：按高内聚业务逻辑将开放时间与规则拆解为独立的卡片容器（Card），建立明确的视觉层级与边界。
2. **严格保持现有文案与样式**：
   - 所有已有的字段标签、提示语、占位符、开关文案 100% 保持原样。
   - 所有字体大小（`text-sm` / `text-xs`）、开关尺寸（`h-6 w-11`）保持原样不变。
3. **消除横向挤压**：数字限制项采用 3 列排布（`grid grid-cols-3 gap-4`），在 500~600px 抽屉内自适应良好。

## 卡片划分方案 (Card Structure)

### 方案 A（平铺独立卡片 - 推荐）
将单一大容器替换为 4 个同级、语义明确的卡片（`p-4 bg-neutral-50 rounded-2xl border border-neutral-200 space-y-4`）：
- **卡片 1：预约与取消时间窗口**
  - 标题：预约与取消时间窗口
  - 3 列输入项：最少提前时间(分)、最多提前天数、临期取消阈值 (分)
- **卡片 2：预约时长与忙闲时规则**
  - 标题：预约时长限制
  - 3 列输入项：单次最小时长 (分)、单次时长上限 (分)、单日时长上限 (0表示无限制)
  - 忙时配置：忙时时段 (全周通用) 及添加
  - 超限策略：允许忙时超单次时长上限、允许闲时超单次时长上限
- **卡片 3：开放规则**
  - 标题：开放规则
  - 规则列表与星期批量添加
  - 特殊时段：允许可预约时段外预约
- **卡片 4：权限与审批设置**
  - 人员白名单（及白名单文本框）
  - 自动审批
  - 隐藏仪器
  - 自动释放爽约时段

### 方案 B（大容器 + 嵌套白底子卡片）
保留外层“开放时间设置”大卡片背景，内部通过 4 个白底子卡片（`p-3.5 bg-white rounded-xl border border-neutral-200 space-y-3`）进行视觉隔离。
