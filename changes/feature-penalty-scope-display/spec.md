# 规格说明书: 在页面上展示惩罚规则的作用范围 (Scope)

## 问题分析
当前系统支持给违规惩罚规则配置“作用范围（指定仪器）”，即 `trigger.scope` 字段（一个包含仪器 ID 的数组）。然而，目前在以下两个关键页面中并未向用户或管理员展示该配置，容易造成误解：
1. **学生端的违规查询页面 (`ViolationQuery.tsx`)**：在“具体处罚规则说明”卡片中，触发条件描述未提及特定仪器范围。
2. **管理端的惩罚规则页 (`PenaltyRulesTab.tsx`)**：在规则列表的“触发条件”列中，没有提示该规则是否限制在特定的仪器上。

## 修复方案
1. **更新 `ViolationQuery.tsx` (违规查询页面)**：
   需要通过请求获取仪器列表。在 `getTriggerDesc` 函数拼接触发条件描述时，加入作用范围的具体仪器名称说明。
   例如：若规则限制了 2 台仪器，原本显示 “在过去的 30 天内，迟到 或 爽约次数达到 3 次”，更新后显示为 “在过去的 30 天内，使用仪器A、仪器B时，迟到 或 爽约次数达到 3 次”。
2. **更新 `PenaltyRulesTab.tsx` (管理端规则列表)**：
   在规则表格的“触发条件”列内容后，当存在特定范围时，增加一个 `<Info />` 提示图标。利用已有的 `equipments` 数据，在鼠标悬停时（Hover）以气泡的形式展示被选中的具体仪器名称列表。
