# 报表图表展示优化 (Reports Chart Display Enhancement)

## 需求背景
目前报表页面中，按用户维度统计的条形图在数据量较多时，因固定容器高度的限制，会出现显示拥挤或部分姓名不显示的问题。内部的图表内容被强制压缩，体验不佳，并且无法让用户一览全局。

## 目标
1. 取消图表内部的固定高度限制，让整个容器自然向下延伸，用户可通过浏览器的全局滚动条进行查看，体验更统一连贯。
2. 为条形图动态计算高度，每个数据条目分配基础 `24px` 的高度，同时预留固定的 X 轴及边距尺寸。
3. 针对 Y 轴标签（姓名等），动态计算最长文本的长度，并设置合理的最大宽度（如 150px 左右）。
4. 保证刻度标签完整显示（不被 Recharts 自动省略）。
5. 图表数据排序随统计指标（时长/费用）联动：当用户切换统计指标时，图表 Y 轴自动按照当前选择的指标进行降序排列，无需额外开关。
6. Y 轴长文本由截断兜底改为多行折行 (Multiline wrapping) 兜底：当文本超过最大宽度时自动换行显示，并且对应调整单行的高度以适应多行文本。

## 详细设计

### 1. 数据逻辑前置与动态高度计算
- 现有的 `h-96` 固定高度将被移除。
- 将图表数据的生成逻辑（如 `chartData` 和 `keyAxis`）从 `<ResponsiveContainer>` 内部提升到组件外层作用域，以便在外层 div 渲染前就可以读取到 `chartData.length`。
- 高度计算公式：
  - **柱状图 (BarChart)**：`Math.max(384, chartData.length * dynamicRowHeight + 80)` （预留 80px 的高度留给 X 轴和上下边距）。其中 `dynamicRowHeight` 根据文本是否折行动态判断（默认 `24px`，如果存在折行文本可放大至 `40px` 等）。
  - **折线图 (LineChart)**：维持 `384px` 的最小高度或固定高度。

### 2. Y 轴宽度动态计算与长文本折行
- 遍历 `chartData`，通过检测各数据条目对应 `keyAxis` 的字符串长度，估算 Y 轴需要的渲染宽度。
- 每个中文字符/英文字母按一定的估算像素（如中文字符按14px，英文按8px估算）累加得出最大长度。
- 设定 Y 轴的最大宽度（例如 `150px`）。如果计算出的理论宽度超过该值，则使用最大宽度 `150px`。
- 在自定义的 Y 轴 `Tick` 组件中，对于超出 `150px` 的文本，通过切分字符串生成多个 `<tspan>` 节点实现 SVG 内的文本折行。

### 3. 显示完整性保证
- 为 `<YAxis>` 添加 `interval={0}`，强制让所有刻度标签全部渲染。由于已经动态分配了适应折行的行高，标签不会出现上下重叠的情况。

### 4. 排序逻辑与指标联动
- 在向图表传递数据前，根据当前的 `chartMetric`（`total_hours` 或 `total_revenue`）对 `chartData` 进行降序排列。
- 确保无论是用户、导师还是仪器维度的条形图，都能以数据大小直观展示排名。
