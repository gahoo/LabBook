- [x] **1. 提取图表数据计算逻辑**
  - 将 `chartData` 和 `keyAxis` 的获取逻辑从 `ResponsiveContainer` 内部移动到外部包裹层，以便提前获取数据数组的长度和内容。

- [x] **2. 实现 Y 轴宽度动态估算**
  - 新增宽度计算函数，遍历当前展示的 `chartData`，找出最长标签文本。
  - 根据字符长度估算所需的像素宽度，并应用最大宽度限制（例如 max 150px），确保长名字不会无限挤压图表主体空间。

- [x] **3. 支持图表容器动态高度**
  - 移除原先硬编码的 `h-96` 外层容器。
  - 对柱状图（BarChart）应用动态高度样式 `style={{ height: Math.max(384, chartData.length * 24 + 80) }}`，确保每个条目有足够的 24px 间距展示；对折线图（LineChart）保留固定高度。

- [x] **4. 优化 YAxis 渲染配置**
  - 传入第2步计算出的动态 `width`。
  - 添加 `interval={0}` 参数强制渲染所有刻度。
  - 增加自定义 Tick 组件，对超过最大宽度的文本进行截断并追加省略号，确保排版不乱。

- [x] **6. 增加数据维度排序逻辑**
  - 在生成 `chartData` 后，根据当前选择的 `chartMetric` ('duration' 对应 'total_hours', 'revenue' 对应 'total_revenue') 进行降序排列。
  - `chartData = [...chartData].sort((a, b) => b[metricKey] - a[metricKey])`。

- [x] **7. 修改 Y 轴 Tick 以支持文本折行**
  - 弃用之前用省略号截断的方法。
  - 在 `CustomYAxisTick` 中，如果计算出的文本宽度超过 `maxLabelWidth` (150px)，则将文本拆分为多行数组，并通过渲染多个 `<tspan x={-8} dy={index === 0 ? 0 : "1em"}>` 节点来实现折行。
  
- [x] **8. 根据折行动态调整图表高度**
  - 在外层遍历 `chartData` 时，记录是否有文本发生了折行（宽度计算 > `maxLabelWidth`）。
  - 如果存在至少一条折行文本，将单行分配高度由默认的 `24px` 放大至例如 `36px`。
  - 将此动态高度应用到 `style={{ height: ... }}` 的公式中。

- [x] **9. 测试与验证**

  - 观察超长仪器名称在图表左侧的显示情况，确认多行折行并带有足够行高的效果是否符合预期。
